# Data availability and archival policy

The Galaxy workflow definition and compact summary results were intended for GitHub. The full Prodigal and eggNOG outputs were not committed because of their size. Any future external hosting or public release of CCB-derived MAG sequences and annotation files requires authorization from the dataset owners. The GitHub-to-Zenodo integration will be used for the **repository release**; no Zenodo release should be initiated until the repository contents and permissions are approved.
