# CCB MAG Taxonomy and Functional Annotation

Galaxy-based taxonomy and functional annotation of quality-screened Cuatro Ciénegas Basin MAGs. GTDB-Tk, Prodigal, and eggNOG-mapper are documented here. CCB CheckM2 quality assessment occurred in a separate Galaxy history.

**Status:** Repository setup in progress; no release published. See `docs/METHODS.md` for provenance and limitations.

This project uses CCB MAGs, not the dataset used in the [MAG reconstruction demonstration](https://github.com/AminatShokunbi/Metagenomic-MAG-Reconstruction-Galaxy).
