# Prodigal gene prediction

Prodigal was configured in the CCB Galaxy workflow to predict protein-coding sequences from quality-filtered MAGs. Its predicted protein FASTA output served as the input to eggNOG-mapper. The full Prodigal outputs were too large for ordinary GitHub commits and were **not uploaded** to this repository. No Prodigal-specific total gene count or per-MAG prediction statistics are reported here because the complete Prodigal outputs were not supplied for independent analysis.

The eggNOG archive contained 626,123 annotation records; this is **not** presented as a verified total of all Prodigal predictions, because unannotated predictions may not be represented equivalently in the export.
